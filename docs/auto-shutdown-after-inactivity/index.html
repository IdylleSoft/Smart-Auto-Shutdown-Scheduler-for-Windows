WINDOWS 11 & WINDOWS 10 GUIDE

Walk away from your PC.
Let it respond thoughtfully.

An inactivity rule can lock, sleep, or shut down the computer after no keyboard or mouse activity for a period you choose. It is useful—but only when the action matches what “away” means in your setup.

What “inactivity” actually means

The Inactivity Monitor watches for keyboard and mouse input. If there is no input for your chosen time, it can run the action you selected. This is an excellent signal when a person has left the desk, but it is not a general “nothing is happening” detector.

A video, a music player, a download, a game update, or a long export may still be working while there is no keyboard or mouse movement. Plan those cases separately with a timer, schedule, or a monitor that matches the task.

Think of it as a presence rule: use inactivity when you want the computer to act after the person leaves—not simply when the screen becomes quiet.

Pick the least disruptive action first

The right action depends on why you are automating the PC:

  1. Lock: ideal for privacy when you step away. It keeps work open and is the safest first test.
  2. Sleep: useful for a personal PC that should save power but resume quickly.
  3. Shut Down: best when you truly want to end the session after a longer period away.

Restart, Hibernate, and Sign Out are also available when they better fit the device. Save work before using any action that can close applications.

Set a realistic idle period

Open Inactivity Monitor, choose the action, then set the amount of keyboard and mouse inactivity required before it runs. Start with a generous duration. For example, a short lock rule can protect a shared desk, while a shutdown rule should usually allow enough time for breaks, meetings, and meals.

Enable the rule, step away briefly, and test it while you are nearby. Confirm that the action happens at the expected time and that the cancellation route is clear. A real test is better than discovering an overly short setting in the middle of a workday.

Avoid accidental shutdowns

Keep the pre-action warning enabled for actions such as shutdown, restart, hibernate, or sign out. It gives you a final opportunity to cancel when you return just as the idle period ends. The desktop widget can also keep the next action in view while the main app stays out of the way.

Turn off or cancel the monitor before watching a long video, leaving a download running, or starting an unattended task unless the selected action is still appropriate. Inactivity and background work often happen at the same time.

Inactivity shutdown FAQ

Can Windows shut down after I stop using the keyboard and mouse?

Yes. Set an Inactivity Monitor action and an idle period. The action runs after no keyboard or mouse activity for that duration.

Will it interrupt a video or a download?

It can, because playback and downloads may continue without keyboard or mouse input. Disable the monitor or use a different automation for those tasks.

Is Lock safer than Shut Down?

For a first-time setup, yes. Lock protects privacy without closing open programs, so it is a good way to test your chosen idle duration.

Can I cancel the action?

Yes. Keep the pre-action warning enabled for disruptive actions so you can cancel when the rule is about to run.
