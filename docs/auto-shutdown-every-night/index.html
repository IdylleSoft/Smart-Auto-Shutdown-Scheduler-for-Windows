WINDOWS 11 & WINDOWS 10 GUIDE

End every night
with a quieter PC.

A nightly shutdown routine makes sense when your workday, shared computer, or home setup has a predictable end. The trick is making it deliberate enough that it never surprises you.

Use a routine, not a one-time schedule

A one-time schedule is for a particular date. “Every night at 11 PM” is a repeating pattern, so it belongs in a Routine. Keeping the two separate helps you understand whether an automation will run only once or continue next week.

In Auto Shutdown & Scheduler, open Routine, choose Shut Down, set the time, and select the days when it should run. You can create a seven-day routine, or select only weekdays if weekends are different.

Start conservatively: choose a time later than your normal work or gaming hours for the first few nights. You can move it earlier once you know it never interrupts something important.

Pick the days that match real life

The safest nightly routine is rarely “every day” by default. Consider how your week actually works:

  1. Weekdays only: a good fit for a work PC that should be off after the normal workday.
  2. Every night: useful for a shared or family computer with a consistent overnight rule.
  3. Selected days: best when you work late, play online, or run long tasks on only certain evenings.

Use a schedule rather than a routine when there is an exception: a late meeting, an overnight backup, or a single day when the PC needs to remain on.

For weekdays, selected days, rotating shifts, and exception planning, see the recurring shutdown schedule guide →.

Keep a final warning

Before any shutdown runs, save open work. The app can display a configurable warning before the action so a person who is still using the PC can cancel it. That is especially useful on a shared device, where someone else may be active after your usual bedtime.

The optional desktop widget can show the upcoming action while the main window is closed. It gives a quiet reminder that a routine is active without forcing you to keep the full app open.

Pause or cancel when plans change

Routines should serve your habits, not trap you in them. Before travel, a late project, or an overnight download, return to the Routine page and cancel the active rule. Create a one-time schedule instead if the exception has a known end time.

Review recurring automations occasionally. A small review at the start of a new work pattern prevents an old routine from becoming an unexpected shutdown months later.

Nightly shutdown FAQ

Can I make my Windows PC shut down every night?

Yes. Create a recurring Routine, choose Shut Down, set the time, and select the days you want it to run.

Can I set it for weekdays only?

Yes. Select Monday through Friday and leave Saturday and Sunday unselected.

What happens if I am still using the PC?

Save your work before the scheduled time. A pre-action warning can give you time to cancel the routine if you are still active.

Can I stop the nightly routine temporarily?

Yes. Cancel the active routine when you need the PC to stay on overnight, then set it up again when the routine is useful.
